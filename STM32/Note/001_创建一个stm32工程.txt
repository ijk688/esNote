工程的创建需要用的keil5 MDK软件

1.新建一个空项目，选择使用的芯片类型
2.空项目根目录中创建Start,User,Library文件夹，并将固件库中的官方文件导入

start:存放芯片启动文件、内核底层文件
包含文件典型：
startup_stm32f10x_hd.s 启动汇编文件（必选，根据芯片容量选择 hd/md/ld）
core_cm3.c / core_cm3.h （Cortex-M3 内核函数，NVIC、SysTick 等）
system_stm32f10x.c / .h 系统时钟初始化底层文件
功能：
上电后最先执行启动汇编，完成堆栈初始化、中断向量表、跳转到 main 函数；
提供内核底层寄存器操作，没有 Start 文件夹程序根本无法启动。

Library:存放ST 官方提供的标准外设库驱动代码
典型文件分组：
stm32f10x_gpio.c、stm32f10x_usart.c、stm32f10x_exti.c…… 各类外设驱动
stm32f10x_rcc.c（时钟）、misc.c（中断分组）
对应全部.h 头文件
功能：
封装了所有片上外设（GPIO、串口、ADC、定时器等）寄存器操作。你不需要直接读写寄存器，调用库函数（GPIO_Init()、USART 初始化函数），属于底层硬件驱动层，不写业务逻辑。

User:自己写的程序
典型文件：
main.c 主函数
stm32f10x_conf.h 库配置头文件（选择启用哪些外设库）
stm32f10x_it.c / .h 中断服务函数
自己新建：led.c、key.c、uart.c 等应用驱动
功能：
存放用户业务逻辑代码。调用 Library 里的官方库函数，实现项目功能（点灯、按键、通信逻辑）。
原则：尽量不修改 Library 和 Start 里的官方源文件，方便后续升级固件库。

3.进行必要设置，如字体，字符编码，编译器版本，宏定义，添加路径，debug方式，直接复位等等
4.完成后在User文件夹中创建一个main.c文件，进行代码编写，并编译，下载工程到开发板
